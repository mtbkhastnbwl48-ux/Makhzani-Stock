# مخزني – نسخة أولى

تطبيق أندرويد عربي لإدارة المخزون بدون إنترنت أثناء الاستخدام.

الميزات الحالية:
- إضافة مادة واسم وكود وكمية افتتاحية.
- إدخال كمية للمخزن.
- إخراج كمية من المخزن.
- عرض الرصيد الحالي.
- حفظ البيانات محلياً داخل الهاتف.
- حذف المادة بالضغط المطوّل.

## البناء
افتح المجلد في Android Studio، ثم انتظر Gradle Sync، وبعدها Build > Build APK(s).
Android Studio هو بيئة التطوير الرسمية لأندرويد، وGradle يبني ملف APK.
